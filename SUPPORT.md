# Support

AGENTintel is maintained by a single person, and no formal service-level agreement applies.

## Where to ask

- Bug reports and feature requests: open a GitHub issue using the provided templates.
- Questions about behavior or contribution process: open a regular issue with `support` context.
- Security-sensitive concerns: use https://github.com/MaxJafar/AGENTintel/security/advisories.

## What to include

- Version (for example `1.0.0`)
- Operating system and Python/Go/Node versions
- Exact commands you ran
- Short, sanitized repro steps and outputs
- Any logs, error text, and expected vs actual output

## Service expectation

This repository is an alpha project and is maintained by one person. We do our best to respond quickly, but there is no SLA and no guaranteed response window.
