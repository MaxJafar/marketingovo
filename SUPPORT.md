# Support

- Use GitHub Discussions for questions, ideas, workflows, and integration
  design.
- Use GitHub Issues for reproducible bugs and accepted work.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; do not publish a
  working exploit in an issue.

Community support is best effort. Maintainers aim to acknowledge security
reports within two business days and triage well-formed bugs within five
business days, but these are targets rather than an SLA.

There is no commercial support tier, no paid SLA, and no hosted edition to
escalate to. Best effort is the whole offer.
