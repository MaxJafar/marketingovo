# Community Edition and GolemWorkers

Community Edition is the strong local, single-user product in this repository. Golem SEO on GolemWorkers is a separate proprietary service for managed infrastructure and collaboration.

Paid value comes from running and coordinating the system for teams—not from deliberately weakening local analysis.

## Capability comparison

| Capability                                        | Community Edition                     | GolemWorkers                                      |
| ------------------------------------------------- | ------------------------------------- | ------------------------------------------------- |
| Projects and audits                               | Unlimited within local resources      | Hosted portfolio at contracted scale              |
| Static and JavaScript crawl                       | Included                              | Included on managed workers                       |
| Technical, on-page, content, links, and CWV       | Included                              | Included plus hosted modules                      |
| GSC, GA4, Trends, SerpAPI, and DataForSEO         | Bring your own provider access        | Managed credentials and optional provider credits |
| Versioned Project Context and marketer journal    | Included locally                      | Shared organization context and governance        |
| Actions, evidence, history, and comparison        | Included                              | Shared across teams and portfolios                |

## Choose Community when

- one operator owns the workflow;
- the machine can remain available for the required run or schedule;
- provider access should remain under direct local control;
- local HTML, PDF, CSV, or JSON reports are sufficient;
- you want to inspect or extend rules and connector contracts;
- hosted collaboration is not a requirement.

## Choose GolemWorkers when

- monitoring must run whether or not a workstation is active;
- several people need shared projects, roles, approvals, and audit logs;
- an agency needs portfolio or white-label delivery;
- provider access, credits, billing, or scale should be managed;
- hosted reports and integrations must reach other business systems;
- retention, SLA, or enterprise support is required.

## Portable projects

Community can export a versioned `.golemseo` bundle containing project
configuration, Project Context revisions, marketer journal history, issue
fingerprints, review decisions and reasons, actions, metrics, and artifact
metadata. Secrets are excluded. Import into GolemWorkers requires authentication
and reconnecting integrations.

Portability is for project data, not a transfer of provider authorization.
